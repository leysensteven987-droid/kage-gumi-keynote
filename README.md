# 影組 Kage-gumi — Keynote

A self-contained, branded keynote deck introducing **Kage-gumi** (Shadow Crew Protocol) — a
multi-agent AI system for WebCenter work — to a mixed audience of managers, R&D, leadership,
support, and solution architects.

Built for presenting **live in a room**: full-screen slides, no scroll, fonts embedded
(works fully offline — no CDN).

- **Navigate:** `←` / `→` · `Space` · `PgUp` / `PgDn` · click the on-screen arrows · swipe
- **Fullscreen:** `F` · **Overview grid:** `O` · **Jump:** number keys `1`–`9` · `Home` / `End`

## Hosting

The deck is a single `index.html` with everything inlined. Served via GitHub Pages
(`main` branch, root).

Source of truth: `docs/kage-gumi-keynote.html` in the [kage-gumi](https://github.com/leysensteven987-droid/kage-gumi)
repo — this repo is the publish target. Update there, then copy over and push.
